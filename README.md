# 🤖 Bot003 - Agentic RAG Frontend

Interfaz de usuario moderna y profesional para el sistema de **Agentic RAG** especializado en contrataciones públicas del Perú.

## 🚀 Características

- **Chat en tiempo real:** Streaming de respuestas (SSE) con visualización de estado del agente.
- **Fuentes Dinámicas:** Visualización de documentos citados con enlaces directos.
- **Autenticación Multi-modo:** Soporte para Firebase Auth (Email/Google) y acceso como invitado.
- **Diseño Premium:** Construido con Tailwind CSS v4, shadcn/ui y soporte para temas (Dark/Light).
- **Responsive:** Optimizado para dispositivos móviles y escritorio.

## 🛠️ Stack Tecnológico

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS v4
- **Componentes:** shadcn/ui & Radix UI
- **Auth:** Firebase Authentication
- **Iconos:** Lucide React

## 📦 Instalación y Uso

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/rjohannanas/bot3-fronted.git
   cd bot3-fronted
   ```

2. **Instalar dependencias:**
   ```bash
   pnpm install
   ```

3. **Configurar variables de entorno:**
   Crea un archivo `.env` basado en `.env.example` con tus credenciales de Firebase y la URL del backend.

4. **Correr en desarrollo:**
   ```bash
   pnpm dev
   ```
